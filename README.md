🌐 Cara Upload ke GitHub Pages (Gratis)
Langkah 1 — Buat Akun GitHub
Daftar gratis di github.com jika belum punya akun.
Langkah 2 — Buat Repository Baru
Klik tombol "+" di pojok kanan atas → New repository
Isi nama repository, contoh: undangan-dicky-siti
Pilih Public
Klik Create repository
Langkah 3 — Upload File
Di halaman repository, klik "uploading an existing file"
Drag & drop kedua file berikut:
index.html ← ganti nama dari undangan-nikah.html jadi index.html
README.md
Klik Commit changes
⚠️ Penting: File HTML harus bernama index.html agar GitHub Pages bisa membacanya.
Langkah 4 — Aktifkan GitHub Pages
Klik tab Settings di repository
Scroll ke bawah → klik Pages di menu kiri
Di bagian Source, pilih:
Branch: main
Folder: / (root)
Klik Save
Langkah 5 — Dapatkan Link Publik
Tunggu 1–2 menit, lalu link undangan kamu akan aktif di:
Code
Ganti USERNAME dengan username GitHub kamu.
